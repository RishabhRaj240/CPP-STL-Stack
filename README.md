## 🚀 Getting Started

### 1. Prerequisites
Ensure you have the following installed locally:
- Git
- C++17 / C++20 (GCC / Clang)


### 2. Installation

```bash
# Clone repository
git clone https://github.com/RishabhRaj240/modern-cpp-app.git
cd modern-cpp-app

# Compile with g++ or clang++ (C++17)
```

```bash

./app
```
